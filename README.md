# Radar de oportunidades

Escáner diario (GitHub Actions) de ~540 acciones (S&P 500 + Nasdaq-100 + ADRs LatAm) con reglas objetivas de momentum/ruptura/despertar y un filtro de calidad (cap ≥ $10bn, rentable, ventas no cayendo, no extendida). Publica `candidatos.json`, que un analista automático lee cada tarde para investigar a fondo las candidatas. No contiene datos personales ni posiciones. Herramienta de análisis, no asesoría financiera.
